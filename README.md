# CCNA ITN Trainer

Интерактивный тренажёр по курсу Cisco CCNA: Introduction to Networks (17 модулей) и лекциям.

- 600+ вопросов трёх уровней: базовый, применение, понимание
- 13 генераторов бесконечных задач: подсети IPv4, VLSM, IPv6, EUI-64, порты, поля заголовков, маршрутизация
- режимы «Практика» и «Экзамен», статистика по темам (хранится в браузере)

Один статический файл `index.html`, без сборки и зависимостей.

## Запуск локально
Просто открой `index.html` в браузере.

## Деплой
Vercel → Add New → Project → Import этого репозитория → Framework Preset: **Other** → Deploy.
